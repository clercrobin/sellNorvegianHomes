## 🎓 Pro Tips

**For Better Results:**
1. Always specify "in French" (en français)
2. Include target audience demographics
3. Specify word count limits
4. Request multiple variations
5. Ask for A/B test variations
6. Include your brand voice (warm, professional, inspiring, etc.)
7. Reference specific pain points
8. Request SEO keywords to include

**Refining Prompts:**
- Too generic? Add more context and constraints
- Too long? Specify exact word/character count
- Wrong tone? Describe the exact feeling you want
- Need variations? Ask for "5 different approaches"
